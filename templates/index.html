Étape 6 : Limites du modèle linéaire

Réponse : {{ r.reponses.residus }}

Explications possibles

  • Effet de seuil : le chauffage se déclenche sous une certaine température, ce qu'une droite représente mal.
  • Relation non linéaire avec l'heure : la consommation a deux pics par jour, alors que le modèle utilise l'heure comme un nombre croissant.
  • Interactions non capturées : l'effet de la température n'est pas le même la nuit, le jour ou le week-end.
  • Variables manquantes : humidité, occupation, ensoleillement, jours fériés.
  • Peu de données : quelques jours d'entraînement seulement.

Pistes d'amélioration

  • Ajouter des variables : consommation décalée (1 h, 24 h, 168 h), moyennes glissantes, heure encodée en sinus / cosinus, jours fériés.
  • Utiliser un modèle non linéaire : arbres, forêts aléatoires, gradient boosting (XGBoost).
  • Utiliser plus de données et une validation croisée temporelle (TimeSeriesSplit).
